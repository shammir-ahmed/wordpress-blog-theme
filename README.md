# ModernBlog WordPress Theme

ModernBlog is a premium-quality WordPress theme focused on blogs, magazines, news, articles, and content-based websites. It is clean, fast, modern, SEO-friendly, and highly customizable.

## Features
- Fully responsive design
- Elementor compatibility with custom widgets
- WordPress Customizer options
- Accessible and SEO optimized
- Clean and modern aesthetics

## Installation
1. Download the theme repository as a ZIP or clone it directly into your `wp-content/themes/` directory:
   ```bash
   cd wp-content/themes/
   git clone https://github.com/shammir-ahmed/wordpress-blog-theme.git modernblog
   ```
2. In your WordPress admin panel, go to **Appearance > Themes**.
3. Locate **ModernBlog** and click **Activate**.
